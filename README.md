##GuessMyNumber

Ein einfaches Terminalspiel programmiert mit Java.

Der Computer erstellt zufällig eine Zahl zwischen 0 und 100. Gib im Terminal eine Zahl ein, von der du denkst, dass es sich um die Zahl des Computers handelt. 
Wenn du die Zahl erraten hast, dann hast du gewonnen und das Spiel ist beendet. Wenn du die Zahl nicht erraten hast, dann wird diese Zahl in der Attempts-Liste 
gespeichert damit du einen Überblick hast über die Zahlen, die du bereits genannt hast. Das Spiel geht so lange weiter bis du die Zahl erratest.
